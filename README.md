## 📖 О проекте

**Weather Diary** — это графическое приложение для ведения дневника наблюдений за погодой. Добавляй записи о температуре, осадках и описании, фильтруй по дате и температуре, смотри статистику. Все данные сохраняются в JSON.

---

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| ➕ Добавление записи | Дата, температура, описание, тип осадков |
| 🗑️ Удаление | Удали ненужную запись |
| 🔍 Фильтрация | По дате (точное совпадение) и по температуре (> , < , = , >= , <=) |
| 📊 Статистика | Количество записей, солнечные/дождливые/снежные дни, макс/мин температура |
| 🌡️ Средняя температура | Быстрый расчёт средней температуры за все время |
| 💾 Автосохранение | Сохранение в JSON и загрузка при запуске |
| 🛡️ Валидация | Дата в формате ГГГГ-ММ-ДД, температура от -90°C до +60°C |
